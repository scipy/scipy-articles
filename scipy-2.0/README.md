# SciPy 2.0 Manuscript

## Local Compilation of the Manuscript

The compile the manuscript locally, you can either use an existing LaTeX installation
or use the `pixi` task runner. To install `pixi`, see the
[pixi documentation](https://pixi.prefix.dev/latest/installation/).
Then to build the manuscript simply run `pixi run build` within the `scipy-2.0` directory
and the resulting manuscript will be built in the `build` directory.
